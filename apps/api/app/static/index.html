AUDITORÍA CRIPTOGRÁFICA

Verificar evidencia

Subí cualquier copia de un archivo PDF, JPEG o PNG. FieldLedger computa su huella SHA-256 y consulta el contrato de Hyperledger Fabric: si el archivo fue alterado un solo byte, la verificación fallará.

  • Límite de archivo: 10 MiB
  • Consulta descentralizada con MSP de AuditorOrg
  • Sin fallback en base de datos
